# 🛒 ShopSphere

ShopSphere is a responsive e-commerce shopping website where users can browse products, search for products, add products to a cart, and place orders.

## ✨ Features

- 🏠 Home page
- 🔎 Product search
- 🛍️ Product categories
- 🛒 Add to Cart
- ➕ Increase product quantity
- ➖ Decrease product quantity
- ❌ Remove products from cart
- 💰 Automatic total price calculation
- 📦 Checkout system
- 👤 Customer details
- 💳 Multiple payment options
- 📋 Order details
- 📅 Order date and time
- 💾 LocalStorage for cart and order data
- 📱 Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
- Browser LocalStorage
